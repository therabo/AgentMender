# ADR-0032 — Caller-scoped session resolution

Use a read-only, caller-scoped resolution operation alongside existing discovery.
The originating Codex chat delegates intent and evidence analysis to Luna Medium.
The parent checks the interpretation against the live request, then owns tool
calls. Native agent registration selects the model where available. Discovery
references and continuations stay in the originating chat because MCP routing
metadata may identify each subagent as a different conversation. AgentMender
validates the search and evidence without invoking a model.

Freeze the user-confirmed constraints and bounded lexical branches together.
Collect original and targeted alternate matches on the same traversal. Start
with a metadata title prior within each eligible inventory window and keep
source-bound FTS5/BM25 passages. Batch existing reader operations and expose
one candidate per canonical identity. The prior only changes visit order.
Candidate batches remain provisional and the resolver retains continuation.

Keep bounded resolution state in the existing read-only MCP process, scoped to
the apparent caller and exact root. Historical text is inert. Luna returns
typed assessments and cites only evidence issued for that candidate. Revalidate
cited source revisions and the frozen conditions at publication. Disclose
unassessed candidates, unfinished scans and logical coverage gaps separately.
An outcome contradiction applies to the cited evidence. Session-wide absence
requires the stronger existing complete-coverage contract.

The read-only runtime acquires no approval, ownership or lifecycle authority.
Existing discovery, diagnostics, management and context contracts remain usable.
The resolution process creates no transcript index or on-disk search state.
